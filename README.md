# projf_pizza_sul

Primeiro projeto flutter em grupo feito em aula.

Eu fiquei na parte de digitar os codigos, pois eu era o unico que possuia o computador.

Esse projeto foi feito para mostrar nossa ideia de um sistema de auto-atendimento. Porém, o objetivo do projeto era aplicar: As transições das páginas, a aparência das páginas, Botões e adaptação para celular e computador.
